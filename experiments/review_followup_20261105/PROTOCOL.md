## Pre-evaluation structural checks

The neural generator uses four output channels because the pinned attention fusion applies LayerNorm over channels; a one-channel output would make that module constant by construction. This was identified from source before any calibration fitting or scoring. The empty-history attention guard unmasks one dummy key only on all-masked rows; upstream presence masking still zeros its contribution. Dense-history outputs must be bit-identical to the original module. These checks do not tune on test outcomes.
